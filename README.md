# TUI Media Tracker

A TUI app for tracking movies and shows you've watched and want to watch using the TMDB API.

---

## How to Use

1. Clone git repo
2. Type `pipx install /path/to/repo_root_dir/` in terminal
3. Get a TMDB API key from [here](https://developer.themoviedb.org/docs/getting-started) (it's free)
4. Go to the root of the repo directory and create a `.env` file
5. Open the file and type `TMDB_API_KEY=paste_api_key_here`
6. Type `media-tracker` in terminal
